# mic-lock
MIC LOCK это небольшая программа для Windows 10/11, которая держит чувствительность (уровень записи) микрофона на одном и том же значении. Если Windows или другое приложение понижает громкость вашего голоса, программа сразу возвращает уровень обратно. Работает с любым микрофоном, который виден в Windows.

Как работает. Вы задаёте ползунком нужный уровень от 0 до 100% и включаете кнопку «ЗАЩИТА». После этого программа каждые 0,1 секунды проверяет текущий уровень микрофона и, если он изменился, мгновенно возвращает его к заданному. Это не драйвер ядра: используется стандартный аудио-интерфейс Windows, права администратора не нужны.

Что есть в интерфейсе

Пиксельное окно со шкалой из блоков: зелёные блоки показывают текущий уровень, красная метка показывает цель.
Выбор микрофона из списка. 
Кнопка «ТЕКСТ» переключает в консольный режим с командами: status (состояние), list (список микрофонов), use N (выбрать микрофон), set 0-100 (задать уровень), lock и unlock (включить и выключить защиту).
Настройки (уровень, состояние защиты, выбранный микрофон) сохраняются и подхватываются при следующем запуске.
